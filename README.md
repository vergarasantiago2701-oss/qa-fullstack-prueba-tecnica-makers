# Prueba Técnica QA Full Stack

Repositorio con los tres módulos de la prueba técnica: automatización web, diseño de pruebas funcionales y testing de API.

**Autor:** Santiago Vergara Serpa

## Contenido

- **Módulo de Automatización** — Smoke test del inicio de sesión de [SauceDemo](https://www.saucedemo.com/), automatizado con Cypress y JavaScript.
- **Módulo Funcional** — Diseño de pruebas para MakersPay (billetera digital): escenarios, casos de prueba, reporte de bugs y las técnicas y tipos de prueba aplicados.
- **Módulo API** — Pruebas funcionales sobre la API pública [reqres.in](https://reqres.in/api/), ejecutadas y documentadas con Postman.
